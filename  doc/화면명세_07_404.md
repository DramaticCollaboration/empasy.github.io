# 📝 화면 명세서: 404 (Page Not Found)

## 1. 개요
*   **경로:** `/page-not-found` 및 와일드카드 `*` 라우트
*   **목표:** 사용자가 길을 잃었을 때 빠르게 홈 또는 주요 페이지로 이동 유도.

## 2. 화면 구성 (Sections)

### **Section 1: Error Visual & Message**
*   **비주얼:** 단순하고 친근한 일러스트(연결이 끊긴 노드 등).
*   **메시지:** "요청하신 페이지를 찾을 수 없습니다."

### **Section 2: Quick Links**
*   **버튼:** [홈으로 가기] [제품 보기] [검색하기]

## 3. 기능 요구사항
1.  **자동 포커스:** 키보드 접근성(메인 액션 버튼에 포커스).
2.  **로그 수집:** 404 발생 시 경로/리퍼러 로깅(분석용).
