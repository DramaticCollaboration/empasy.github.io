# 📝 화면 명세서: SyncCrawl (Data)

## 1. 개요
*   **경로:** `/synccrawl` (또는 `/page-synccrawl`)
*   **목표:** 지능형 웹 크롤링 및 B2B 데이터 수집 자동화 역량 홍보.

## 2. 화면 구성 (Sections)

### **Section 1: Hero Visual**
*   **비주얼:** 거미줄 형태의 데이터 노드 맵, 수집→정제→적재 파이프라인.
*   **카피:** "지능형 크롤링으로 비즈니스 데이터 자산을 만듭니다."

### **Section 2: Core Features**
1.  **Smart Selector:** DOM 변화에 강한 동적 셀렉터.
2.  **Anti-Bot Bypass:** 헤더/세션 전략, 지연 주기, 프록시 로테이션.
3.  **Scheduler:** 주기적 수집/증분 수집, 실패 재시도.
4.  **Export:** CSV/JSON/DB 적재 및 RAG 파이프라인 연동.

### **Section 3: Compliance & Ethics**
*   **내용:** 이용 약관 준수, Robots.txt, 합법적 데이터 활용 가이드.

## 3. 기능 요구사항
1.  **실시간 크롤링 데모:** 키워드 입력 → 미니 리스트 결과 시뮬레이션.
2.  **보안/법무 안내:** 크롤링 정책 안내 배너 고정.
