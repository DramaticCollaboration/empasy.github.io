# 📝 화면 명세서: SyncAdmin (Admin)

## 1. 개요
*   **경로:** `/syncadmin`
*   **목표:** Vue 3 기반 모던 백오피스 관리 플랫폼 홍보.

## 2. 화면 구성 (Sections)

### **Section 1: Hero Visual**
*   **비주얼:** 정교한 데이터 대시보드 및 차트 인터페이스 비주얼.
*   **카피:** "가장 민첩한 백오피스 구축의 시작, SyncAdmin"

### **Section 2: Core Features**
1.  **Vue 3 & Quasar:** 최신 프레임워크 기반의 고성능 UI.
2.  **RBAC:** 정교한 역할 기반 권한 관리 시스템.
3.  **Data Visualization:** 내장된 다양한 차트 및 리포팅 도구.
4.  **Responsive:** 모든 디바이스 최적화 관리자 화면.

### **Section 3: Customization Strategy**
*   **내용:** 기업별 고유 비즈니스 로직에 맞춘 UI 커스텀 가이드.

## 3. 기능 요구사항
1.  **다크모드 토글:** 관리자 화면의 다크/라이트 모드 테마 변경 미리보기.
