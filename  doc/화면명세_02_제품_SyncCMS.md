# 📝 화면 명세서: SyncCMS (Content)

## 1. 개요
*   **경로:** `/synccms`
*   **목표:** 엔터프라이즈 모듈형 콘텐츠 관리 시스템 홍보.

## 2. 화면 구성 (Sections)

### **Section 1: Hero Visual**
*   **비주얼:** 모듈형 블록이 조립되는 아이소메트릭 일러스트.
*   **카피:** "유연하고 강력한 엔터프라이즈 CMS, SyncCMS"

### **Section 2: Core Features**
1.  **Modular Structure:** 필요한 기능만 선택 조립하는 유연성.
2.  **SEO Native:** 검색 엔진 최적화 기본 탑재.
3.  **Multi-Language:** 글로벌 사이트 대응 다국어 관리 도구.
4.  **Visual Layout:** 드래그 앤 드롭 방식의 페이지 관리.

### **Section 3: Dashboard Preview**
*   **콘텐츠:** 실제 CMS 관리자 화면 스크린샷 및 주요 UI 설명.

## 3. 기능 요구사항
1.  **반응형 프리뷰:** CMS 관리 도구가 모바일/태블릿에서 어떻게 보이는지 데모 제공.
