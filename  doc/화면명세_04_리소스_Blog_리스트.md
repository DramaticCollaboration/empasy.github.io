# 📝 화면 명세서: 기술 블로그 리스트 (Resources > Blog)

## 1. 개요
*   **경로:** `/blog`
*   **목표:** 기술 권위성(Authority) 강화 및 상세 글로의 전환 유도.

## 2. 화면 구성 (Sections)

### **Section 1: Header & Search**
*   **카피:** "Empasy Insights"
*   **검색:** 키워드 입력(예: MSA, 테스트 자동화, LLM)

### **Section 2: Category/Tag Filter**
*   **카테고리:** AI/LLM, QA/Test, DevOps/MSA, Web/Mobile
*   **태그:** #제조 #금융 #공공 #Automation #RAG 등

### **Section 3: Post Grid/List**
*   **항목:** 썸네일, 제목, 요약, 태그, 예상 읽기 시간, 작성일.
*   **인터랙션:** 호버 시 '자세히 보기'.

## 3. 기능 요구사항
1.  **동적 필터링:** 페이지 새로고침 없이 결과 반영.
2.  **SEO:** 목록 페이지 메타/구조화 데이터.
