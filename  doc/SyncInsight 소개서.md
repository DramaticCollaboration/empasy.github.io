# **SyncInsight: 온프레미스 AI 기반 기업용 인사이트 솔루션**
### **"분산된 데이터, 하나의 통찰력으로"**
**(Synchronize Distributed Data into Single Insight)**

---

## **1. 제품 개요 (Product Overview)**
**SyncInsight**는 기업 내부에 흩어진 데이터(문서, DB)와 외부 웹 데이터(뉴스, 시장 정보)를 AI 에이전트가 수집·분석하여, **의사결정에 필요한 '심층 리포트'를 자동으로 생성해 주는 온프레미스(On-Premise) 지식 플랫폼**입니다.

보안이 중요한 금융/공공/엔터프라이즈 환경에서 **데이터 유출 걱정 없이** 최신 LLM(거대언어모델)과 RAG(검색 증강 생성) 기술을 활용하여 **"리서치 리포트 자동화 에이전트"**를 구축할 수 있습니다,,.

---

## **2. 3대 핵심 가치 (Key Value Proposition)**

### **① 완벽한 데이터 주권 (Data Sovereignty)**
*   **On-Premise 구축:** 모든 데이터 저장소, AI 모델 서버, 벡터 DB가 기업 내부망에 구축되어 외부로의 데이터 유출을 원천 차단합니다.
*   **규제 준수:** 엄격한 산업별 보안 규제 및 개인정보보호법을 준수하며 안전하게 AI를 활용할 수 있습니다,.

### **② 리서치 및 보고서 자동화 (Automated Research)**
*   **AI Agent:** 사용자가 주제를 입력하면, AI 에이전트가 웹 크롤링(SyncCrawl 연동), 사내 문서 검색, Python 스크립트 실행을 통해 자료를 조사하고 분석합니다.
*   **Time Saving:** 수작업 대비 리서치 및 보고서 작성 시간을 최대 **90% 단축**하여, 실무자가 고부가가치 업무에 집중할 수 있게 합니다,.

### **③ 엔터프라이즈 최적화 (Enterprise Ready)**
*   **Spring AI 기반:** 안정성이 검증된 Java/Spring 기반의 오픈소스 AI 프레임워크를 채택하여 기존 기업 시스템과의 연동 및 확장성이 뛰어납니다.
*   **DeepResearch 기술:** LangChain4j와 Playwright MCP를 활용한 심층 탐색 기술로 단순 검색을 넘어선 '통찰력'을 제공합니다,.

---

## **3. 주요 기능 및 프로세스 (Key Functions)**

SyncInsight는 **수집 $\rightarrow$ 분석 $\rightarrow$ 지식화 $\rightarrow$ 보고**의 4단계 파이프라인을 자동화합니다,.

| 단계 | 상세 기능 |
| :--- | :--- |
| **1. 사용자 요청** | • 웹 기반의 대화형 UI를 통해 리서치 주제 및 요구사항 접수 |
| **2. 멀티 소스 수집** | • **내부:** 기업 지식 베이스(Wiki, 문서중앙화) 커넥터 연동<br>• **외부:** 웹 크롤러(SyncCrawl)를 통한 시장 동향, 뉴스, 경쟁사 정보 수집 |
| **3. 심층 분석** | • **RAG (검색 증강 생성):** 벡터 DB(Vector DB)를 활용하여 정확한 근거 기반의 답변 생성<br>• **Python 실행:** 데이터 통계 분석 및 시각화 차트 생성 |
| **4. 리포트 생성** | • 수집된 정보를 종합하여 서론-본론-결론이 갖춰진 **'심층 리포트'** 자동 작성<br>• 출처(Source) 표기를 통한 신뢰성 확보 |

---

## **4. 시스템 아키텍처 (Architecture)**

SyncInsight는 유기적으로 연결된 **멀티 에이전트 시스템**으로 구성되어 있습니다,.

*   **Frontend:** 사용자 친화적인 대화형 웹 UI (React/Vue)
*   **Backend (Workflow Engine):** Spring AI 기반의 에이전트 오케스트레이션 및 그래프 워크플로우 관리.
*   **AI Core:**
    *   **LLM:** 사내 구축형 Llama/Mistral 모델 또는 보안 프록시를 통한 외부 API 연동.
    *   **Vector DB:** FAISS, Qdrant 등을 활용한 고성능 지식 저장소.
*   **Tools:** 웹 크롤러, 문서 파서(Parser), Python 샌드박스.
