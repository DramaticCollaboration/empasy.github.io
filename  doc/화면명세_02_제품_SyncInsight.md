# 📝 화면 명세서: SyncInsight (AI Analytics)

## 1. 개요
*   **경로:** (TBD) — 온프레미스 RAG 기반 분석 플랫폼. 기획서 사이트맵의 '상세 예정' 항목.
*   **목표:** 데이터 주권을 지키는 사내 지식 플랫폼의 비전 제시 및 티저.

## 2. 화면 구성 (Sections)

### **Section 1: Vision Teaser**
*   **비주얼:** 문서 아이콘들이 깔때기를 통과해 하나의 리포트로 정제되는 인포그래픽.
*   **카피:** "데이터는 밖으로 나가지 않습니다. 통찰만 나갑니다."

### **Section 2: Core Capabilities**
1.  **On-Premise LLM:** 내부망 전용, 데이터 유출 Zero.
2.  **RAG Engine:** 사내 문서 기반 정확한 응답.
3.  **Multi-Agent:** 수집-분석-보고 자동 협업.

### **Section 3: Use Cases**
*   **예:** 정책 문서 요약, 로그 분석 리포팅, Q&A 지식베이스.

## 3. 기능 요구사항
1.  **티저 폼:** 자세한 자료 요청(리드 수집) 폼 노출.
2.  **알림 구독:** 출시 알림 이메일 구독 기능.
