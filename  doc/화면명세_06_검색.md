# 📝 화면 명세서: 통합 검색 (Search)

## 1. 개요
*   **경로:** `/search`
*   **목표:** 사이트 전반(제품/블로그/사례/문서)의 통합 검색 제공.

## 2. 화면 구성 (Sections)

### **Section 1: Search Bar**
*   **기능:** 자동완성(제품/블로그/문서 구분), 최근 검색어, 인기 키워드.

### **Section 2: Results (탭형)**
*   **탭:** 전체 | 제품 | 블로그 | 문서/리소스
*   **항목 공통:** 제목, 요약, 위치(경로), 태그.

### **Section 3: 필터 & 정렬**
*   **필터:** 기간, 카테고리, 제품군.
*   **정렬:** 정확도/최신순.

## 3. 기능 요구사항
1.  **키보드 내비게이션:** 방향키로 자동완성 이동, Enter 검색.
2.  **하이라이트:** 매칭 키워드 하이라이트 처리.
