# **SyncCrawl: 지능형 B2B 데이터 수집 및 자산화 솔루션**
### **"흩어진 웹 데이터를 살아있는 비즈니스 통찰력으로"**
**(Intelligent Web Crawling & B2B Knowledge Solution)**

---

## **1. 제품 개요 (Product Overview)**
**SyncCrawl**은 웹상에 흩어진 방대한 비정형 데이터(뉴스, 경쟁사 정보, VOC 등)를 **AI 기술로 수집, 정제하여 기업의 지식 자산(Asset)으로 변환**해 주는 지능형 크롤링 솔루션입니다.

기존의 단순 스크립트 기반 크롤러가 가진 **'잦은 차단'**과 **'유지보수의 어려움'**을 극복하기 위해, **Playwright MCP**와 **LLM(거대언어모델)**을 결합하여 동적인 웹 환경에서도 사람처럼 유연하게 데이터를 수집합니다.

*   **핵심 가치:** 데이터의 단순 수집을 넘어, **RAG(검색 증강 생성)** 기술과 연동하여 **'의사결정을 돕는 인사이트'**를 제공합니다.
*   **출시 예정:** 2025년 11월 (전략 제품)

---

## **2. 3대 핵심 경쟁력 (Key Differentiators)**

### **① 자연어 기반 제어 (Natural Language Control)**
*   **기능:** 복잡한 코딩 없이 **"A사 쇼핑몰에서 노트북 가격 정보를 수집해줘"**와 같은 자연어 명령만으로 수집 규칙을 생성하고 실행합니다.
*   **기술:** LLM이 사용자의 의도를 분석하여 대상 사이트의 구조(DOM)를 파악하고, 최적의 수집 경로를 자동으로 설계합니다.

### **② 웹 환경 적응성 (High Adaptability)**
*   **기능:** React, Vue 등으로 제작된 **동적 웹사이트(SPA)**나 무한 스크롤, 팝업 등 복잡한 UI 환경에서도 데이터 누락 없이 수집합니다.
*   **기술:** **Playwright MCP** 기반의 브라우저 제어 기술과 **Dynamic DOM Parsing** 엔진이 UI 변경을 실시간으로 감지하고 대응합니다.

### **③ RAG 기반 지식 창출 (Knowledge Creation)**
*   **기능:** 수집된 원본 데이터(Raw Data)를 그대로 저장하는 것이 아니라, AI가 요약, 분류, 매핑하여 **'활용 가능한 정보'**로 가공합니다.
*   **연동:** 수집된 데이터는 벡터 DB(Vector DB)에 저장되어, 향후 **SyncInsight(AI 분석 솔루션)**와 연동 시 답변의 정확도를 높이는 지식 베이스로 활용됩니다.

## **3. 주요 기능 (Key Functions)**

| 기능 모듈 | 상세 내용 |
| :--- | :--- |
| **지능형 수집기** | • URL 및 키워드 기반 자동 수집<br>• 정적/동적 페이지 자동 판별 및 하이브리드 수집 전략 적용 |
| **우회 및 방어** | • 캡차(CAPTCHA) 자동 탐지 및 우회 지원<br>• IP 로테이션 및 브라우저 핑거프린팅 관리로 차단 방지 |
| **데이터 정제** | • HTML 태그 제거, 본문 추출, 중복 데이터 필터링<br>• 비정형 텍스트의 구조화(JSON/Excel 변환) |
| **스케줄링** | • 주기적 수집(일/주/월) 및 변동 사항 모니터링<br>• n8n 워크플로우와 연동하여 수집 후 자동 알림 발송 |
| **VOC 분석** | • 여러 채널(커뮤니티, 뉴스, SNS)의 고객 반응을 통합 수집<br>• 긍정/부정 감성 분석을 위한 기초 데이터셋 생성 |

## **4. 시스템 아키텍처 및 기술 스택**

SyncCrawl은 엔터프라이즈급 성능과 안정성을 위해 검증된 최신 기술 스택으로 구성되어 있습니다.

*   **Backend:** Java, Spring Boot (안정성 및 확장성)
*   **Crawler Engine:** Python, Playwright, Selenium (브라우저 제어)
*   **AI Core:** LangChain4j, OpenAI/Mistral LLM (의도 파악 및 데이터 가공)
*   **Frontend:** Vue 3, Quasar Framework (관리자 대시보드)
*   **Database:** PostgreSQL(메타데이터), Vector DB(임베딩 데이터)

---

## **5. 활용 사례 (Use Cases)**

1.  **경쟁사 모니터링:** 경쟁 쇼핑몰의 상품 가격, 재고 변동, 프로모션 정보를 실시간으로 파악하여 가격 정책 수립에 활용.
2.  **VOC 및 트렌드 분석:** 뉴스, 블로그, SNS에서 자사 브랜드에 대한 고객의 목소리를 수집하여 리스크 관리 및 마케팅 전략에 반영.
3.  **컴플라이언스 리스크 관리:** 관련 법규나 규제 변경 사항을 정부 사이트에서 주기적으로 수집하여 담당자에게 알림.
4.  **데이터 바우처 사업:** 고객이 원하는 특정 도메인의 데이터를 수집 및 가공하여 납품 (데이터 가공 기업 역할 수행).
