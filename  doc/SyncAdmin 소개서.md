# **SyncAdmin: 엔터프라이즈 프론트엔드 개발의 가속화**
### **"복잡한 관리자 화면을 레고(Lego)처럼 쉽고 빠르게"**
**(Accelerate Your Admin Development with Vue 3 & Vite)**

---

## **1. 제품 개요 (Product Overview)**
**SyncAdmin**은 **Vue 3, Vite, TypeScript** 등 최신 프론트엔드 기술을 기반으로 구축된 **엔터프라이즈 관리 시스템(Admin) 템플릿**입니다.

중대형 규모의 백오피스(Back-Office) 및 대시보드 구축에 최적화되어 있으며, 단순한 화면 디자인을 넘어 **검증된 UI 컴포넌트와 비즈니스 로직(권한, 다국어 등)이 내재화**된 솔루션입니다. 개발자는 '화면 껍데기'를 만드는 시간을 절약하고, 핵심 비즈니스 로직 개발에 즉시 착수할 수 있습니다.

---

## **2. 핵심 기술 및 차별점 (Key Features)**

### **① 압도적인 개발 생산성 (Productivity)**
*   **컴포넌트 기반 개발:** 잘 만들어진 재사용 가능한 UI 컴포넌트(버튼, 폼, 테이블 등)를 **'레고 블록'** 조립하듯 배치하여 복잡한 관리자 화면을 신속하게 구축합니다.
*   **Vite 기반 초고속 빌드:** 기존 Webpack 대비 월등히 빠른 빌드 속도와 **HMR(Hot Module Replacement)** 기능을 제공하여, 코드 수정 사항을 브라우저에서 실시간으로 확인하며 개발할 수 있습니다.

### **② 최신 기술 스택 (Modern Tech Stack)**
*   **Core:** **Vue 3** (Composition API) 기반으로 설계되어 유연하고 강력한 성능을 보장합니다.
*   **Type Safety:** **TypeScript**를 전면 도입하여 코드의 안정성을 높이고 런타임 오류를 사전에 방지합니다.
*   **State Management:** **Pinia**를 사용하여 직관적이고 효율적인 상태 관리를 지원합니다.

### **③ 강력한 권한 관리 (Permission Control)**
*   단순한 페이지 접근 제어를 넘어, 사용자 역할(Role)에 따른 **동적 라우팅(Dynamic Routing)**과 **버튼 단위의 세밀한 권한 제어** 기능을 기본 제공합니다.
*   백엔드(SyncBoot)의 RBAC(Role-Based Access Control) 시스템과 매끄럽게 연동됩니다.

### **④ 글로벌 비즈니스 대응 (i18n)**
*   국제화(i18n) 모듈이 내장되어 있어, **다국어 웹사이트** 및 글로벌 관리자 페이지를 손쉽게 구축할 수 있습니다. 2026년 글로벌 진출을 목표로 하는 기업에 필수적인 기능입니다.

## **4. Sync Series 시너지 (Integration)**

SyncAdmin은 엠파시의 백엔드 플랫폼인 **SyncBoot**와 결합될 때 최고의 성능을 발휘합니다.

*   **SyncBoot (Backend) + SyncAdmin (Frontend):** SyncBoot가 제공하는 RESTful API를 SyncAdmin이 완벽하게 시각화합니다.
*   **개발 속도 혁신:** 백엔드에서는 **코드 생성기**로 API를 만들고, 프론트엔드에서는 **SyncAdmin 컴포넌트**로 화면을 구성하여 SI 프로젝트 기간을 획기적으로 단축합니다.
