### **[화면 명세서] Sync Series: SyncEta (AI 테스트 자동화)**

#### **1. Hero Section (최상단 비주얼 및 컨셉)**
*   **화면 목적:** 코딩이나 화면 녹화(Recording)조차 필요 없는 SyncEta의 압도적인 기술 혁신성 강조.
*   **카피라이팅:**
    *   (메인) "사람처럼 이해하고, 기계처럼 테스트하라"
    *   (서브) "코드 작성도, 화면 녹화도 필요 없습니다. 당신의 엑셀 문서가 즉시 실행 가능한 테스트가 되는 Zero-Recording AI 테스트 플랫폼."
*   **동적 구성 요소 (Dynamic Elements):**
    *   **타이핑 & 변환 모션:** 화면 중앙에 거대한 엑셀 셀(Cell) UI가 나타나며, *"결제 플로우 테스트: 장바구니 추가 후 쿠폰 적용해줘"*라는 자연어가 타이핑됩니다. 엔터를 치는 순간 엑셀 셀이 파티클로 부서지며 뒤편에 숨겨져 있던 복잡한 Playwright 자동화 코드로 실시간 변환되어 빛나는 애니메이션이 연출됩니다.
    *   **패럴랙스 브라우저 레이어:** 배경에는 여러 겹의 투명한 웹 브라우저 창들이 겹쳐져 있으며, 마우스 움직임에 따라 각 브라우저 창에서 테스트가 병렬로 자동 실행되는 듯한 3D 패럴랙스(Parallax) 효과가 적용됩니다.

#### **2. Zero-Recording Execution (엑셀 직접 실행 기술)**
*   **화면 목적:** 기존 Record & Playback 방식의 한계를 넘어선 '문서가 곧 실행(Action)'이 되는 Hyper-Automation 기술 시각화.
*   **동적 구성 요소 (Dynamic Elements):**
    *   **스크롤 인터랙션 (Before & After 비교):**
        *   스크롤 진입 시 좌측에는 기존의 **"수작업 코딩 (AS-IS)"** 애니메이션(개발자가 땀 흘리며 코드를 짜는 묘사)이 나타나며 게이지 바가 '3~5일 소요'를 가리킵니다.
        *   스크롤을 더 내리면 화면이 부드럽게 반전되며 우측의 **"AI 직접 실행 (TO-BE)"** 영역이 활성화됩니다. 엑셀 파일 아이콘이 'AI Recognition Engine'을 통과하자마자 여러 대의 스마트폰/모니터 아이콘에서 동시에 테스트가 성공하는(Green Check) 초고속 파이프라인 모션이 재생됩니다.
        *   배경에는 **"테스트케이스 작성 시간 80% 절감"**이라는 숫자가 빠르게 카운트 업(Count-up) 됩니다.

#### **3. Self-Healing & Visual QA (자가 진화 및 시각 검증)**
*   **화면 목적:** UI가 변경되어도 테스트가 중단되지 않는 자가 복구 능력과 픽셀 단위 검증 기술 안내.
*   **카피라이팅:** "UI가 바뀌어도 멈추지 않는 지능형 테스트, 그리고 픽셀 단위의 완벽한 시각 검증."
*   **동적 구성 요소 (Dynamic Elements):**
    *   **인터랙티브 Self-Healing 시뮬레이터:**
        *   사용자가 화면 내 가상의 '로그인 버튼' 위치를 마우스로 드래그하여 다른 곳으로 옮겨버릴 수 있습니다.
        *   버튼이 이동하면 기존 스크립트를 상징하는 빨간선이 끊어지며 경고(Error)가 발생하지만, 즉시 'SyncEta AI Brain' 아이콘이 스캐닝 레이저를 쏘며 새로운 버튼의 위치와 DOM 구조를 찾아내어 연결선(XPath/Universal Locator)을 파란색(Success)으로 자동 복구하는 인터랙션이 제공됩니다.
    *   **Visual Regression 돋보기 효과:** 모바일 웹 화면 이미지 위에 마우스를 올리면 돋보기 툴이 활성화되며, 숨겨져 있던 1픽셀의 UI 레이아웃 깨짐(Visual Bug)을 붉은색으로 정밀하게 잡아내는 효과를 체험할 수 있습니다.

#### **4. Real-time Dashboard & TestOps (실시간 관측 및 결함 증빙)**
*   **화면 목적:** 재현 불가능한 간헐적 오류(Flaky Test)까지 잡아내는 멀티미디어 포렌식 및 모니터링 환경 강조.
*   **동적 구성 요소 (Dynamic Elements):**
    *   **라이브 대시보드 애니메이션:** 실제 SyncEta 대시보드와 유사한 형태의 UI가 펼쳐집니다.
        *   실시간으로 '초저지연 소켓 통신'을 상징하는 데이터 파동(Wave) 그래픽이 흐르고, 수백 개의 Headless 브라우저가 병렬로 실행되는 현황이 깜빡이는 상태등(Status indicator)으로 표시됩니다.
    *   **에러 포렌식 호버 (Hover Video Playback):** 대시보드 내 빨간색 에러 로그 행(Row)에 마우스를 올리면(Hover), 해당 에러가 발생하기 직전의 브라우저 동작을 기록한 **'타임머신 레코딩(Time-Machine Recording)'** 미니 비디오 플레이어가 말풍선 형태로 팝업되어 자동 재생됩니다.

#### **5. AI Feedback Loop (지속적 품질 개선 루프)**
*   **화면 목적:** QA의 피드백을 통해 모델이 자체 학습(LoRA/RAG)하며 지속적으로 영리해지는 차별화된 선순환 구조 설명.
*   **카피라이팅:** "사용할수록 더 똑똑해지는 QA 파트너, Self-Evolving AI"
*   **동적 구성 요소 (Dynamic Elements):**
    *   **순환 루프 (Infinite Loop) 애니메이션:** [QA 엔지니어의 리뷰] $\rightarrow$ [수정 데이터 수집] $\rightarrow$ [LoRA 기반 LLM 재학습] $\rightarrow$ [더 정교한 테스트 생성]으로 이어지는 원형 파이프라인(뫼비우스의 띠 형태)을 따라 데이터 입자(Data particles)들이 끊임없이 순환하며 빛을 냅니다.
    *   그래프 모션: 데이터 입자가 루프를 한 바퀴 돌 때마다 중앙의 'AI 정확도(Accuracy)' 라인 차트가 50%에서 90% 이상으로 부드럽게 우상향하며 그려집니다.

#### **6. CI/CD Pipeline Integration (DevOps 생태계)**
*   **화면 목적:** 개발 전 주기에 걸친 'Zero-Touch' 자동화 체계 구현.
*   **동적 구성 요소 (Dynamic Elements):**
    *   **드롭다운 파이프라인 라우팅:** Jenkins, GitHub Actions, Jira, Slack 등의 로고가 컨베이어 벨트 위에 놓여 있습니다. 코드가 커밋되는 아이콘이 떨어지면, 컨베이어 벨트가 작동하며 SyncEta 검증 블록을 거쳐 Jira 이슈 자동 등록 및 Slack 알림으로 도달하는 파이프라인 워크플로우 전체가 도미노처럼 실행되는 역동적인 모션을 보여줍니다.

#### **7. Bottom CTA (Call To Action)**
*   **화면 목적:** 문의 페이지 이동 및 도입 상담 유도
*   **카피라이팅:** "QA 업무의 병목 현상, 지금 SyncEta의 AI와 함께 해결하십시오."
*   **동적 UI:** '문의하기' 버튼 주위로 AI의 스캐닝을 연상케 하는 네온(Neon) 테두리 선이 계속해서 회전하는 인터랙션을 적용하여 클릭을 적극적으로 유도합니다.
