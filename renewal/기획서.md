
# [기획서] ㈜엠파시 홈페이지 개편 기획서

## 1. 개편 개요 및 목표
*   **프로젝트명:** ㈜엠파시 AI-DLC 중심 웹사이트 리뉴얼
*   **핵심 컨셉:** **"Boon to business by agility (비즈니스 민첩성을 위한 혜택)"**
*   **주요 목표:**
    1.  **AI-DLC 생태계 조명:** AI 개발 수명주기(착수-구축-운영)를 자동화하는 'Hydra'를 중심으로 엠파시의 기술적 진보성 강조.
    2.  **Sync Series(자사 솔루션) 통합 브랜딩:** SyncBoot, SyncEta, SyncCMS, SyncAPIM, SyncShop 등 개별 솔루션의 전문성과 시너지(SyncVerse) 부각.
    3.  **전문성 입증(Use Cases):** 엔터프라이즈급(LG, 삼성, 효성 등) 구축 사례를 통해 B2B 고객의 신뢰도 확보.

## 3. 주요 화면 상세 명세 (Screen Specifications)

각 페이지별 화면 구성 요소와 전달해야 할 핵심 콘텐츠 명세입니다.

### 📍 [화면 1] Main (홈페이지 메인)
*   **Hero Section (최상단):**
    *   **Visual:** 클라우드와 AI 에이전트들이 연결되는 동적인 네트워크 애니메이션.
    *   **Copy:** "AI-DLC 중심의 디지털 혁신, 비즈니스 민첩성을 극대화하다 (Boon to business by agility)".
*   **AI-DLC 파이프라인 소개 (Hydra & SyncVerse):**
    *   착수(Inception) → 구축(Construction) → 운영(Operations)으로 이어지는 AI 생태계를 인포그래픽으로 표현하고 각 단계별 엠파시 솔루션 매핑.
*   **Our Solutions (Sync Series 요약):**
    *   솔루션별 카드형 UI 배치 (SyncBoot, SyncEta, SyncShop 등). 마우스 호버 시 핵심 기능(1줄 요약) 노출.
*   **Trusted by (고객사 로고 롤링):**
    *   LG전자, 삼성전자 DS, 효성ITX, 비상교육, KT, 홈플러스 등.

### 📍 [화면 2] AI-DLC 기반 인프라 자동화: Hydra
*   **개요:** 복잡한 클라우드 설정 없이 자연어 대화만으로 AI 개발 및 서빙 환경을 구축하는 Prompt-Driven AI Infra Orchestrator.
*   **주요 기능 명세:**
    *   **Inception (착수):** 자연어 의도 분석 및 스티어링 파일 주입 (비용/정책 강제).
    *   **Construction (구축):** Terraform / Kubernetes 매니페스트(YAML) 기반 인프라 자동 생성 및 문서화(Auto-Documentation).
    *   **Operations (운영):** Scale-to-Zero(유휴 자원 0원화) 및 스팟 인스턴스 자동 대체 오케스트레이션으로 비용 최적화.

### 📍 [화면 3] 마이크로서비스 플랫폼: SyncBoot
*   **개요:** Java/Spring Boot 기반의 오픈소스 마이크로서비스(MSA) 쾌속 개발 및 클라우드 네이티브 플랫폼.
*   **주요 기능 명세:**
    *   **아키텍처 강점:** 모놀리식의 한계를 극복한 독립적 배포 및 스케일 아웃 기능.
    *   **통합 환경 (E2E):** API 게이트웨이, 서비스 디스커버리(Nacos), 분산 트랜잭션, 서킷 브레이커, CI/CD 툴체인 내장.
    *   **모니터링:** ELK 통합 로그 조회, SkyWalking 트랜잭션 추적, Prometheus/Grafana 시스템 메트릭스.

### 📍 [화면 4] AI 테스트 자동화: SyncEta
*   **개요:** "사람처럼 이해하고, 기계처럼 테스트하라" LLM과 Playwright MCP 기반의 자연어 테스트케이스 직접 제어 솔루션.
*   **주요 기능 명세:**
    *   **Zero-Recording 실행:** 엑셀로 작성된 자연어 테스트 문서를 AI가 해석하여 브라우저 제어 코드로 실시간 변환 및 병렬 실행.
    *   **Self-Healing (자가 진화):** UI/UX 변경 시 에러를 스스로 감지하고 대체 요소를 찾아 테스트를 자동 복구하는 기능.
    *   **TestOps 파이프라인:** CI/CD 연동 및 실패 시 영상/로그 자동 증빙.

### 📍 [화면 5] 이커머스 & 물류 최적화: SyncShop & AI Logistics
*   **개요:** 헤드리스(Headless) 커머스 아키텍처와 물류 자율운영 AI 에이전트의 결합.
*   **주요 기능 명세:**
    *   **SyncShop (eCommerce):** 프론트/백엔드 분리를 통한 옴니채널 대응. 다차원 카테고리/SKU 관리, 주문/배송 워크플로우(OMS), 지능형 마케팅 엔진(타임세일, 쿠폰) 탑재.
    *   **AI Logistics Hub (물류 최적화):**
        *   **Logistics AI:** WMS/OMS 데이터를 연동해 허브별 재고 선배치 및 배송 경로 최적화 (시간/비용 절감).
        *   **Enterprise RAG:** 물류 로그, VOC, 지침 매뉴얼 등을 통합한 AI 대화형 의사결정 지원.

### 📍 [화면 6] 유연한 콘텐츠 관리: SyncCMS
*   **개요:** 개발자와 마케터 모두를 만족시키는 Java 기반의 엔터프라이즈 맞춤형 CMS.
*   **주요 기능 명세:**
    *   **멀티 사이트 & 다국어:** 단일 시스템으로 수십만 개 독립 사이트 및 다국어 환경 동시 지원.
    *   **유연한 템플릿:** Freemarker 엔진 기반, 정적(Static)/동적(Dynamic) 하이브리드 배포 구조 및 페이지 조각(Fragment) 조립 방식.
    *   **마케팅 최적화:** 빌트인 SEO 도구, 리치 에디터 히스토리 추적, 방문자 통계 기능.

### 📍 [화면 7] 지능형 API 통합 관리: SyncApim
*   **개요:** "Customization in its DNA" 철학이 반영된 유연하고 강력한 API 생태계 플랫폼.
*   **주요 기능 명세:**
    *   API 게이트웨이, 개발자 포털, 분석/모니터링 대시보드를 통합한 전체 라이프사이클 관리.
    *   레거시 시스템과 신규 MSA 간의 안전한 브릿지 역할 및 대규모 트래픽 보안 제어 (마이데이터 대응 가능).

### 📍 [화면 8] 엔터프라이즈 성공 사례 (Use Cases)
*   **UI 구성:** 갤러리 또는 타임라인 형태의 카드 뷰. 필터링 제공(SI, CMS, AI, MSA 등).
*   **주요 노출 사례 상세 명세:**
    *   **LG전자 & LG화학 (EAP 2.0):** LGERP 연동 생성형 AI 진단봇 구축 및 SyncEta를 통한 글로벌 상시 회귀 테스트 도입.
    *   **비상교육 (TestOps):** 동시 접속 2,000명 환경에서 SyncEta 병렬 실행으로 교사-학생 상호작용 무결성(Regression Zero) 검증.
    *   **펜타시큐리티 (WAPPLES API):** 금융권 마이데이터 규제를 충족하는 대용량 API 트래픽 제어 플랫폼 구축.
    *   **효성 ITX (SyncInsight/Crawl):** 500여 개 산업 웹사이트 크롤링 관리 및 RAG/LLM 에이전트 기반 Q&A 시스템 구축.
    *   **LX 하우시스:** SyncCMS 기반 글로벌 다국어(US, 중국 등) 15개국 이상 통합 웹사이트 운영.

### 📍 [화면 9] 문의
