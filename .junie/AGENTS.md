# 엠파시 홈페이지 리뉴얼 가이드라인 (Empasy Homepage Renewal Guidelines)

이 문서는 엠파시 홈페이지 개편 작업을 수행하는 AI 에이전트를 위한 지침입니다.

## 🎯 프로젝트 개요
현재 엠파시 홈페이지는 **AI-DLC(AI Development Life Cycle) 중심의 생태계**를 강조하기 위해 완전히 새롭게 개편되고 있습니다.

## 🛠 리뉴얼 작업 원칙
1. **완전한 재구축 (Clean Slate Policy)**
   - 홈페이지 개편 작업 시, **문의 서버 API 호출 부분을 제외하고 기존의 모든 소스 코드(src/, index.html 등)와 콘텐츠를 유지하지 않습니다.**
   - 기존 내용을 수정하거나 보완하는 방식이 아니라, **모든 기존 내용을 삭제하고 처음부터 다시 만드는 것**을 원칙으로 합니다.
2. **참조 문서 준수**
   - 모든 신규 개발은 `renewal/` 디렉토리에 정의된 내용을 바탕으로 진행합니다.
   - `renewal/기획서.md`: 전체적인 사이트 구조(IA) 및 목표 확인.
   - `renewal/화면 명세서-*.md`: 각 페이지별 상세 기능 및 콘텐츠 구현.
3. **핵심 컨셉 유지**
   - "Boon to business by agility (비즈니스 민첩성을 위한 혜택)" 컨셉을 시각적/기능적으로 구현해야 합니다.
   - Hydra 플랫폼을 중심으로 한 AI-DLC 파이프라인(착수-구축-운영)을 명확하게 노출하십시오.

## 📋 기술 스택 및 환경
- **프레임워크**: Vite 기반 React (package.json 참조)
- **주요 스크립트**:
  - `npm run dev`: 로컬 개발 서버 실행
  - `npm run build`: 프로덕션 빌드
  - `npm run build:ssg`: SSG(Static Site Generation) 빌드 실행

## 🌐 다국어 지원 (Multi-language Support)
- 홈페이지는 한국어, 영어, 일본어를 지원하며, 각 언어별 접속 경로는 다음과 같습니다.
  - `/`: 한국어 (기본)
  - `/ko`: 한국어
  - `/en`: 영어
  - `/jp`: 일본어

## ⚠️ 주의 사항
- 기존 `src_old` 폴더나 현재의 `src` 폴더 내용을 재사용하여 과거의 스타일을 유지하려고 하지 마십시오.
- 리뉴얼은 '기존 코드의 개선'이 아닌 '신규 프로젝트의 시작'으로 간주하십시오.
