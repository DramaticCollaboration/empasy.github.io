### **[화면 명세서] Sync Series: SyncAPIM (지능형 API 통합 관리)**

#### **1. Hero Section (최상단 비주얼 및 컨셉)**
*   **화면 목적:** API 생태계의 중심 허브로서의 역할과, 타 솔루션 대비 확장이 자유로운 '맞춤형(Customization)' 플랫폼임을 강조합니다.
*   **카피라이팅:**
    *   (메인) "API Platform with Customization in its DNA"
    *   (서브) "표준화된 시스템의 한계를 넘어, 기업의 비즈니스 환경에 완벽히 동기화되는 지능형 API 통합 관리 플랫폼입니다."
*   **동적 구성 요소 (Dynamic Elements):**
    *   **3D API 게이트웨이 파티클 모션:** 화면 중앙에 거대한 코어(게이트웨이)가 위치하고, 수많은 데이터 파티클(요청)이 외부에서 날아와 코어를 통과한 뒤 각기 다른 색상의 내부 마이크로서비스(MSA) 노드로 안전하게 라우팅되는 3D 플로우 애니메이션이 반복 재생됩니다.
    *   **마그네틱 타이핑 효과:** 서브 카피 아래에 `[ API Gateway ]`, `[ Developer Portal ]`, `[ Analytics ]`, `[ Security ]` 키워드가 차례대로 롤링되며 빛나는 타이핑 효과가 연출됩니다.

#### **2. Full Lifecycle Management (API 전체 라이프사이클 관리)**
*   **화면 목적:** API의 생성부터 배포, 보안, 모니터링까지 단일 플랫폼에서 완벽하게 통제되는 통합 관리 역량 시각화.
*   **카피라이팅:** "설계부터 수익화까지, 하나의 플랫폼에서 완성하는 API 생태계"
*   **동적 구성 요소 (Dynamic Elements):**
    *   **스크롤 텔링(Scroll-Telling) 아키텍처 맵:** 스크롤을 내림에 따라 중앙의 논리 아키텍처 맵(Logical Architecture)에 불이 켜집니다.
        1.  **개발자 서비스 (Developer):** Smart Doc 및 개발자 포털이 활성화되며 API 문서가 자동 생성되는 애니메이션.
        2.  **API 서비스 (Gateway):** 정책 적용, 버전 관리(Versioning), OAuth & Security 방패막이 활성화되는 모션.
        3.  **분석 서비스 (Analytics):** 비즈니스 메트릭스와 앱 성능 지표 차트가 위로 솟아오르는 이펙트.

#### **3. Core Features: 5대 핵심 기능 (Interactive Bento-box)**
*   **화면 목적:** SyncAPIM이 제공하는 핵심 기능 5가지를 사용자가 직접 탐색하며 확인하도록 구성.
*   **동적 구성 요소 (Dynamic Elements):**
    *   **인터랙티브 호버 카드 (Hover Reveal):** 5개의 카드형 UI에 마우스를 올리면 내부에서 동작 시뮬레이션이 재생됩니다.
        *   **① 정책 관리 (Policy):** 마우스 호버 시, 호출 제한(Rate Limiting) 게이지가 꽉 차자마자 접근이 차단되는 블로킹 모션 재생.
        *   **② API 관리 (Management):** 수많은 API 엔드포인트가 그룹 폴더 안으로 깔끔하게 정렬(Drag&Drop)되는 모션.
        *   **③ API 테스트 (Testing):** URL과 헤더 입력 후 'SEND' 버튼이 클릭되며 상태 코드 `200 OK`와 JSON 응답 본문이 출력되는 타이핑 모션.
        *   **④ 모니터링 (Monitoring):** API 성능 및 상태를 추적하는 준실시간 라인 차트가 그려지는 애니메이션.
        *   **⑤ 시스템 알림 (Alert):** 위험 이벤트 발생 시 빨간색 경고등이 깜빡이며 관리자의 스마트폰 아이콘으로 푸시 알림이 전송되는 모션.

#### **4. Enterprise Security & Customization (금융권 수준 보안 및 맞춤형 확장)**
*   **화면 목적:** 금융권 마이데이터 가이드라인을 충족하는 강력한 보안성과 10,000+ TPS를 견디는 대규모 트래픽 처리 능력 어필.
*   **카피라이팅:** "10,000 TPS의 극한 환경에서도 흔들림 없는 맞춤형 보안 아키텍처"
*   **동적 구성 요소 (Dynamic Elements):**
    *   **과부하(Traffic) 쉴드 시뮬레이터:**
        *   화면 우측에 해커 모양의 아이콘과 대규모 트래픽 파동이 공격해 들어옵니다.
        *   화면 중앙의 'SyncAPIM (OAuth 2.0 / JWT / API Key)' 다층 보안 필터가 겹겹이 쉴드를 전개하며 공격을 모두 튕겨내고 무지연(Zero-Latency)으로 데이터를 분산 처리하는 통쾌한 파티클 이펙트를 연출합니다.
    *   **레퍼런스 팝업 툴팁:** 쉴드 하단에 있는 'WAPPLES API Security (펜타시큐리티)' 로고에 마우스를 올리면, *"금융권 마이데이터 규제 대응 및 대용량 트래픽 관제 플랫폼 구축 완료"*라는 증빙 툴팁이 노출됩니다.

#### **5. Observability & Packetbeat Analytics (준실시간 분석 및 인사이트)**
*   **화면 목적:** 물리적 아키텍처 관점에서 Packetbeat 기반의 심층 데이터 수집과 커스텀 리포트 기능을 강조.
*   **동적 구성 요소 (Dynamic Elements):**
    *   **Packetbeat 데이터 스트리밍 모션:**
        *   서버 아이콘(Source)에서 'Packetbeat 에이전트'를 거쳐 다양한 프로토콜 데이터가 시각화된 광섬유 선(Fiber-optic lines)을 타고 분석 대시보드로 쏟아져 들어옵니다.
    *   **실시간 커스텀 대시보드 렌더링:**
        *   데이터가 들어오는 즉시, 화면 상의 파이 차트, 막대그래프, 그리고 지연 시간(Latency) 추적 그래프가 0부터 목표 수치까지 실시간 렌더링되며 카운트 업 됩니다.
        *   "관리자와 개발자에게 API 사용에 대한 완벽한 인사이트 제공" 카피가 서서히 나타납니다 (Fade-in).
