
### **[화면 명세서] Sync Series: SyncBoot (MSA 플랫폼)**

#### **1. Hero Section (최상단 비주얼 및 컨셉)**
*   **화면 목적:** 기존 모놀리식(Monolithic) 아키텍처의 한계를 깨고 마이크로서비스(MSA)로 전환하는 SyncBoot의 핵심 가치 전달.
*   **카피라이팅:**
    *   (메인) "비즈니스 민첩성을 위한 MSA 쾌속 개발 플랫폼, SyncBoot"
    *   (서브) "컨테이너 관리부터 CI/CD, 모니터링, API 게이트웨이까지. E2E 클라우드 네이티브 생태계를 한 번에 구축하세요."
*   **동적 구성 요소 (Dynamic Elements):**
    *   **3D 아키텍처 트랜지션:** 화면 진입 시, 거대하고 무거운 하나의 3D 큐브(모놀리식 시스템 상징)가 화면 중앙에 놓여 있습니다. 마우스를 스크롤하는 순간, 이 큐브가 수십 개의 빛나는 소형 큐브(마이크로서비스)로 분할되며 퍼져나갑니다.
    *   **마우스 패럴랙스(Parallax):** 분할된 소형 큐브들은 네트워크 선(Glowing Lines)으로 서로 연결되어 우주 공간처럼 떠 있으며, 마우스 커서의 움직임에 따라 큐브 군집이 입체적으로 회전합니다.

#### **2. Core Values (SyncBoot의 3대 핵심 경쟁력)**
*   **화면 목적:** SyncBoot가 제공하는 기술적 장점을 명확하게 요약.
*   **동적 구성 요소 (Dynamic Elements):**
    *   **스태킹 카드(Stacking Cards) 스크롤:** 스크롤을 내릴 때마다 3장의 카드가 화면 중앙에 차곡차곡 쌓이는(Stacking) 인터랙션입니다.
        1.  **"100% 오픈소스 기반"**: 벤더 종속성(Lock-in) 없는 검증된 오픈소스 기술 스택 로고들(Spring Boot, Docker, Kubernetes 등)이 팝업 애니메이션으로 등장합니다.
        2.  **"End-to-End 통합 환경"**: 톱니바퀴 아이콘이 맞물려 돌아가며 설계, 개발, 배포, 운영의 파이프라인이 하나의 고리로 연결되는 모션.
        3.  **"Low-Code 개발 생산성"**: 블록을 조립하듯 UI 컴포넌트가 맞춰지며 백엔드 API 코드가 자동으로 생성되는 타이핑 이펙트.

#### **3. Interactive Architecture Map (논리/물리 아키텍처 뷰어)**
*   **화면 목적:** 복잡한 SyncBoot의 내부 아키텍처(서비스 디스커버리, 게이트웨이 등)를 전문가(개발자/CIO)들이 직관적으로 탐색할 수 있도록 제공.
*   **카피라이팅:** "검증된 오픈소스로 구성된 무결점 아키텍처"
*   **동적 구성 요소 (Dynamic Elements):**
    *   **인터랙티브 SVG 맵:** 전체 시스템 아키텍처 도면이 화면에 펼쳐집니다. 사용자가 마우스를 특정 계층(Layer)에 올리면(Hover), 해당 영역만 밝게 하이라이트(Highlight)되며 툴팁 설명이 나타납니다.
        *   *Gateway 계층 Hover:* 라우팅 및 통합 인증(OAuth2, JWT) 애니메이션 노출.
        *   *Service 계층 Hover:* Nacos(서비스 디스커버리)를 통해 마이크로서비스 간 통신(Ping)이 오가는 데이터 플로우 모션(빛의 입자가 이동).
        *   *Data 계층 Hover:* Redis(분산 캐시)와 RDB/NoSQL 간의 데이터 분산 및 동기화 모션.

#### **4. Observability & DevOps (통합 모니터링 및 배포 자동화)**
*   **화면 목적:** 시스템 장애를 사전에 감지하고 대응하는 강력한 관측성(Observability) 및 CI/CD 환경 강조.
*   **동적 구성 요소 (Dynamic Elements):**
    *   **탭(Tab) 스위칭 + 대시보드 애니메이션:** 좌측에 4개의 주요 기능 탭이 있고, 우측에는 해당 기능이 동작하는 가상의 대시보드 화면이 렌더링됩니다.
        1.  **서비스 흐름 조절 (서킷 브레이커 - Sentinel):**
            *   *동적 UI:* 트래픽 게이지가 붉은색(과부하)으로 치솟으면, 경고음 UI와 함께 쉴드(방패) 모션이 펼쳐지며 'Fall-back' 로직으로 트래픽이 우회하는 애니메이션이 재생됩니다.
        2.  **콜체인 모니터링 (SkyWalking):**
            *   *동적 UI:* 마이크로서비스 간의 API 호출 경로(Topology)가 3D 노드로 표시되고, 빨간색 에러 노드를 클릭하면 지연 시간(Latency) 및 오류 코드가 추적(Tracing)되는 인터랙션.
        3.  **통합 로그 및 매트릭스 (ELK & Grafana/Prometheus):**
            *   *동적 UI:* 검은색 터미널 창에서 실시간으로 로그가 위로 스크롤링되며 스트리밍되고, 옆의 원형 차트 지표 숫자들이 실시간으로 카운트 업(Count-up) 됩니다.
        4.  **CI/CD 툴체인 (Jenkins, GitLab):**
            *   *동적 UI:* 소스 코드 푸시 $\rightarrow$ 빌드 $\rightarrow$ 도커 이미지 생성 $\rightarrow$ 쿠버네티스 배포로 이어지는 진행 바(Progress Bar)가 차례대로 녹색(Success)으로 채워집니다.

#### **5. UI Framework & Admin (개발 생산성 혁신)**
*   **화면 목적:** 백엔드 인프라뿐만 아니라, 프론트엔드 관리자 화면(Admin)까지 빠르게 구축할 수 있는 편의성 강조 (SyncAdmin 연계).
*   **카피라이팅:** "표준화된 프레임워크로, 비즈니스 로직에만 집중하세요."
*   **동적 구성 요소 (Dynamic Elements):**
    *   **드래그 앤 드롭(Drag & Drop) 시뮬레이션:** 사용자가 직접 체험할 수 있는 미니 인터랙션 영역입니다. 사용자가 화면 좌측의 '사용자 관리', '권한 관리(RBAC)', '차트 대시보드' 아이콘을 중앙의 빈 캔버스로 드래그 앤 드롭하면, 우측 화면에서 실시간으로 Java/Spring Boot API 코드와 Vue.js 프론트엔드 코드가 자동 생성(Auto-generation)되며 스크롤링되는 모션을 연출합니다.

#### **6. Bottom CTA (Call To Action)**
*   **화면 목적:** 문의 페이지 이동 및 도입 상담 유도.
*   **카피라이팅:** "모놀리식의 한계, 지금 SyncBoot로 넘어서십시오."
*   **동적 UI:**
    *   버튼 위로 마우스를 가져가면 버튼 배경이 엠파시 브랜드 컬러인 민트(Mint) 색상의 물결(Ripple) 효과로 가득 차오릅니다.
    *   배경에는 무한히 뻗어가는 격자 무늬(Grid) 애니메이션을 배치하여 확장성(Scalability)을 시각화합니다.
